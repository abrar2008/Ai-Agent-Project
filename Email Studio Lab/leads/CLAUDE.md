# Leads folder rules

These rules apply to everything in `leads/`.

- **Everyone here is made up.** The people in `leads.csv` are practice leads for The Steep Club launch. They are not real people.
- **Never add real people.** Don't add real names, real email addresses or any other real contact details, even if someone pastes them in. Use made-up names and `@example.com` addresses instead.
- **Every row needs a consent value.** The `consent` column must never be empty. It says how the person agreed to hear from us, such as `waitlist form`. Don't add a row without one.
- **Never change the `@example.com` addresses.** Every email address must end in `@example.com`. That domain is reserved and can never receive mail, so no real person is ever emailed. Don't swap it for any other domain.
- **Keep the format.** The columns are `first_name,last_name,email,group,joined_on,consent`. Groups are `tea-curious`, `gift-buyers` or `daily-drinkers`. Dates use `YYYY-MM-DD`.
